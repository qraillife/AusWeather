🌤️ AusWeather

Live Australian Weather, Made Simple.

AusWeather is a modern, mobile-friendly Australian weather application inspired by the Bureau of Meteorology (BOM). Designed with a clean interface, AusWeather helps Australians stay informed about changing weather conditions.

Built for iPhone, desktop and other modern devices.

🌦️ Features

* 🌡️ Live Weather — Current temperature, conditions and feels-like temperature.
* ☀️ 7-Day Forecast — Plan ahead with daily weather predictions.
* 🕒 Hourly Forecast — View upcoming weather conditions.
* 🌧️ Rain Radar — Interactive radar with rainfall animation.
* ⚠️ Weather Warnings — Quick access to official BOM warnings.
* 💨 Detailed Conditions — Wind speed, humidity, rainfall, UV index and atmospheric pressure.
* 📍 Location Search — Find weather forecasts for Australian towns and suburbs.
* ⭐ Saved Locations — Quickly access favourite locations.
* 🌙 Dark Mode — Comfortable viewing during the day or night.
* 📱 Device Support — Install AusWeather on supported mobile and desktop devices.

📱 Install AusWeather

AusWeather can be used directly through your web browser or installed on supported devices.

iPhone

1. Open the AusWeather website in Safari.
2. Tap the Share button.
3. Select Add to Home Screen.
4. Tap Add.

AusWeather will appear on your Home Screen like an app.

Windows

Google Chrome:

1. Open the AusWeather website in Chrome.
2. Click the three-dot menu in the top-right corner.
3. Select Cast, save and share → Install page as app, or Install AusWeather if available.
4. Click Install.

Microsoft Edge:

1. Open the AusWeather website in Edge.
2. Click the three-dot menu.
3. Select Apps → Install this site as an app.
4. Click Install.

AusWeather can then be opened from the Start menu or desktop shortcut.

macOS

Safari (macOS Sonoma or later):

1. Open the AusWeather website in Safari.
2. Select File → Add to Dock.
3. Choose Add.

AusWeather will be available from your Dock and Applications folder.

Linux

Google Chrome or Chromium:

1. Open the AusWeather website.
2. Open the browser menu.
3. Select Install page as app or Install AusWeather, if available.
4. Confirm the installation.

The app can then be launched from your applications menu.

🛠️ Technology

AusWeather is built using:

* HTML5
* CSS3
* JavaScript
* Open-Meteo Weather API
* RainViewer radar data
* Progressive Web App (PWA) technology

The application uses live online weather services and requires an internet connection for updated weather information.
